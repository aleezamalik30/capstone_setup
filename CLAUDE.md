# Project Conventions

## Stack

- Language: JavaScript / Node.js
- Framework: TBD

## Conventions

- File naming: kebab-case (jaise: my-file-name.js)
- Commit format: Conventional Commits (feat, fix, docs, chore)
- Folder structure: src/ mein source code, tests/ mein tests

## Project Rules Learned from Task 2

1. Inspect the existing project structure before modifying files and reuse the existing React + TypeScript structure instead of introducing unnecessary dependencies.

2. For new features, define expected behavior, validation rules, accessibility requirements, and important edge cases before implementation.

3. Every feature that includes user input should include appropriate validation tests and should be verified by running the tests and production build before completion.

4. Keep UI implementations simple, responsive, accessible, and consistent with the existing project instead of adding unnecessary libraries or visual complexity.
